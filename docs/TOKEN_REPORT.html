Metodología

  • Datos extraídos de las 9 transcripciones locales de Claude Code aún presentes en ~/.claude/projects/…KDE-STICKERS/; sesiones ya rotadas o eliminadas no están incluidas, así que este es un piso, no necesariamente el 100% del consumo histórico.
  • Cada llamada a la API se identifica por su requestId y se cuenta una sola vez a nivel global, aunque el mismo mensaje aparezca duplicado en varios archivos de sesión (2,406 duplicados detectados y descartados) por reanudaciones/forks de conversación.
  • La frontera de versión es el timestamp del commit del tag v1.0.0 (2026-09-07T10:38:51+02:00 → 08:38:51Z): todo mensaje con timestamp igual o anterior cuenta como v1.0.0; todo mensaje posterior cuenta como v1.1.0 (no hay tag más nuevo, así que ese bucket incluye también el trabajo posterior al commit de v1.1.0 hasta hoy).
  • Precios usados: Sonnet 5 $2 / $10 por millón de tokens input/output; Haiku 4.5 $1 / $5; lectura de caché al 0.1× el precio de input; escritura de caché al 2× el precio de input para TTL de 1 hora (1.25× para TTL de 5 minutos, sin uso registrado en este proyecto) — tarifas vigentes consultadas en septiembre de 2026.
  • El historial de commits del proyecto corre del 17 de agosto al 14 de septiembre de 2026.
  • La sesión "Esta conversación" (6dd1714e…) seguía activa al generar este informe: su coste y recuento de tokens crecieron después.
