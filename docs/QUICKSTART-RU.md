## Установка

```bash
cd <путь-к-репозиторию>  # перейдите в каталог, куда вы клонировали репозиторий
chmod +x scripts/install.sh
./scripts/install.sh
```

Это собирает бинарный файл Qt6 (`build/desktop-stickers`), устанавливает
его в `~/.local/bin/desktop-stickers` и регистрирует автозапуск в
`~/.config/autostart/io.github.javierlobo.desktopstickers.desktop`.

## Первый запуск

Приложение запустится автоматически при следующем входе в сеанс Plasma.
Чтобы попробовать его прямо сейчас, не выходя из сеанса:

```bash
~/.local/bin/desktop-stickers &
```

Вы должны увидеть значок в системном трее («Desktop Stickers»), и если у
вас уже есть сохранённые стикеры, их окна появятся в последнем реальном
положении (сохраняется благодаря индивидуальному правилу KWin для
каждого стикера — см. `QA_CHECKLIST.md`). Данные хранятся в
`$XDG_DATA_HOME/desktop-stickers/stickers.json` (обычно
`~/.local/share/desktop-stickers/`), а не в произвольной папке в
домашнем каталоге.

Язык интерфейса определяется тем, что сохранено в Настройках (по
умолчанию — испанский). Чтобы изменить его: правый клик по значку трея
→ **Опции → Настройки → Языки**.

## Создание первого стикера

- Клик по значку в трее → «Nuevo sticker», или
- Клик по кнопке «+» на любом существующем стикере

## Редактирование

Клик внутри стикера переключает его в режим редактирования Markdown —
над текстовой областью появляется панель форматирования (полужирный,
заголовки, списки, таблицы, ссылки…). Клик снаружи возвращает к
отрисованному предпросмотру.

## Закрепление (все рабочие столы) и изменение размера

- Кнопка 📍/📌 в заголовке: переключает, виден ли стикер на всех
  виртуальных рабочих столах (📌) или только на своём (📍). По
  умолчанию новые стикеры создаются без закрепления (настраивается в
  Настройках).
- Перетащите за нижний правый угол, чтобы изменить размер.

## Панель настроек

Правый клик по значку трея → **Опции → Настройки** открывает панель с
четырьмя разделами:

- **Внешний вид**: цвет новых стикеров по умолчанию (случайный,
  акцентный или фиксированный), список предпочитаемых шрифтов и размер
  шрифта
- **Поведение**: видимость панели Markdown по умолчанию, подтверждение
  удаления, действие по левому клику на значок трея
- **Система**: автозапуск вкл/выкл, путь к данным (с кнопкой
  «Открыть»), экспорт/импорт резервной копии
- **Языки**: выбор языка интерфейса

Остальная часть подменю **Опции** содержит: Справка (документация на
GitHub), Поддержать автора, Просмотреть лицензию и О программе.

## Панель заметок

Левый клик по значку в трее (или пункт «Panel de Stickers» в меню)
открывает полный список: поиск по тексту, сортировка по
недавним/алфавиту/цвету, клик для открытия заметки, контекстное меню
(открыть, переименовать, дублировать) и множественное выделение для
удаления сразу нескольких.

## Тестовые данные

⚠️ Этот скрипт **перезаписывает** ваш `stickers.json` — если у вас уже
есть созданные стикеры, они будут потеряны. Используйте его только при
новой установке или если не жаль потерять текущие данные.

```bash
chmod +x scripts/test-sticker.sh
./scripts/test-sticker.sh
```

## Устранение неполадок

**Бинарный файл не собирается:**
- Проверьте, что установлен Qt6 (`Core`, `Gui`, `Qml`, `Quick`, `Widgets`, `DBus`)
- Посмотрите вывод команды `cmake -B build -S .`, чтобы определить
  недостающий пакет

**Стикер не отображается на всех рабочих столах:**
- «Все рабочие столы» — это опция, включаемая **для каждого стикера
  отдельно** через кнопку закрепления (📍/📌) в заголовке, а не общее
  правило для всего приложения — сначала проверьте, что закрепление у
  данного стикера активно (📌).
- Если закрепление активно, но стикер всё равно не следует за вами
  между рабочими столами, проверьте конкретное правило KWin этого
  стикера:
  `kreadconfig6 --file kwinrulesrc --group desktopstickers-sticker-<id> --key desktopsrule`
  должно вернуть `2` (Force). Если возвращается `1` или пусто — значит
  закрепление не записалось, повторите клик по 📌.
- Также проверьте, что группа указана в списке:
  `kreadconfig6 --file kwinrulesrc --group General --key rules` должно
  включать `desktopstickers-sticker-<id>`.
- Если значения верны, но изменения не применяются на лету,
  принудительно перезагрузите конфигурацию:
  `qdbus6 org.kde.KWin /KWin org.kde.KWin.reconfigure`

**Новый язык, который я добавил в `src/i18n/`, не появляется:**
- В нём должны быть ровно те же ключи, что и в `src/i18n/es.json`
  (включая `Language.name` и `Language.flag`).
- Требуется пересборка (`cmake --build build`) — список словарей заново
  определяется только на этапе конфигурации/сборки, а не при запуске
  уже установленного приложения.

**Логи:**
```bash
journalctl --user -f
```
(приложение — самостоятельный процесс, не часть plasmashell, поэтому
его сообщения попадают в лог пользовательского сеанса; запуск
`~/.local/bin/desktop-stickers` напрямую из терминала для просмотра
вывода консоли в реальном времени остаётся наиболее надёжным способом)
