Плавающие стикеры для рабочего стола KDE Plasma. Автономное
Qt6/QML-приложение (не плазмоид), устанавливаемое как обычная программа
с автозапуском — каждый стикер представляет собой отдельное окно без
декораций, с сохраняемыми положением и размером, а также возможностью
для каждого стикера отдельно включить его отображение на всех
виртуальных рабочих столах (закрепление).

## Требования

- Plasma 6.x (проверено на версии 6.7.4) и KWin, сеанс Wayland
- Qt 6.4+ (`Core`, `Gui`, `Qml`, `Quick`, `Widgets`, `DBus`)
- CMake, Bash

## Установка

```bash
chmod +x scripts/install.sh
./scripts/install.sh
```

Собирает исполняемый файл, устанавливает его в
`~/.local/bin/desktop-stickers` и регистрирует автозапуск. Полное
руководство (первый запуск, тестовые данные, устранение неполадок) — в
[QUICKSTART-RU.md](QUICKSTART-RU.md), а чек-лист ручной проверки — в
`QA_CHECKLIST.md`.

## Возможности

- Создание стикеров из значка в системном трее или кнопки «+» на
  существующем стикере (новый стикер появляется каскадом, со смещением
  от того, из которого был создан), с последовательно возрастающим id
- Перетаскивание по рабочему столу (реальное перемещение через
  `Window.startSystemMove()`), при этом реальное положение (сообщаемое
  KWin, а не Qt) сохраняется после каждого перетаскивания и
  восстанавливается при перезапуске благодаря индивидуальному правилу
  окна KWin для каждого стикера (`desktopstickers-sticker-<id>`)
- Изменение размера за нижний правый угол — размер сохраняется и
  восстанавливается так же, как и положение
- Закрепление для каждого стикера отдельно (кнопка 📍/📌): включается
  индивидуально, чтобы стикер был виден сразу на всех виртуальных
  рабочих столах, через то же правило окна KWin; без закрепления
  стикер существует только на том рабочем столе, где он был создан или
  на который был перемещён. Значение по умолчанию настраивается в
  Настройках (Рабочие столы); «из коробки» новые стикеры создаются без
  закрепления
- Редактирование текста в **полном Markdown** (заголовки, таблицы, код,
  цитаты, списки, полужирный/курсив, ссылки, чекбоксы) с автоматическим
  переключением режимов: клик — для перехода к редактированию, потеря
  фокуса — для возврата к отрисованному предпросмотру
- **Панель форматирования Markdown** при редактировании: полужирный,
  курсив, зачёркнутый, заголовки H1–H3, маркированный список,
  нумерованный список, список задач, ссылка, изображение, встроенный
  код, цитата, блок кода, горизонтальная линия и таблица (с выбором
  количества строк и столбцов) — каждая кнопка переключает
  форматирование выделенного текста и имеет собственное сочетание
  клавиш. По мере уменьшения стикера кнопки с более низким приоритетом
  постепенно скрываются справа налево за кнопку «ещё параметры»; всю
  панель можно скрыть из заголовка стикера или по умолчанию — из
  Настроек
- В предпросмотре ссылки кликабельны (открываются через системный
  обработчик URL), а блоки кода в тройных кавычках отображаются в
  рамке с выделенным фоном
- Прокручиваемое содержимое: длинная заметка никогда не выходит за
  пределы стикера, а область редактирования автоматически
  прокручивается, чтобы курсор оставался видимым при наборе текста
- Цвет фона: случайный, акцентный цвет системы (следует за текущей
  темой Plasma) или выбранный вами фиксированный цвет — настраивается
  в Настройках (раздел «Внешний вид»)
- Настраиваемые семейство и размер шрифта в Настройках: упорядоченный
  список предпочтений (например, «Times New Roman» → «Liberation
  Serif»), из которого используется первый шрифт, реально установленный
  на компьютере, плюс настраиваемый кегль
- Имя для каждого стикера, редактируемое в Панели заметок: если не
  задано, определяется автоматически по первой непустой строке текста
  (без ведущих символов заголовка `#`). Обрезается до 30 символов как в
  заголовке стикера (`#<id> | <имя или резервное значение>`), так и в
  меню трея / Панели
- **Панель заметок**: полный, ничем не ограниченный список стикеров, с
  поиском, сортировкой (по недавним / по алфавиту / по цвету),
  открытием по клику, контекстным меню (открыть, переименовать,
  дублировать), множественным выделением и удалением с опциональным
  подтверждением и отменой в течение нескольких секунд
- Значок в системном трее показывает список из 10 последних изменённых
  заметок (без постраничной навигации) — каждая строка открывает
  заметку или переводит на неё фокус
- Кнопка «✕» на стикере только закрывает его окно — заметка при этом
  продолжает существовать и может быть снова открыта из меню трея или
  из Панели. Удаление заметки — отдельное действие, всегда с
  возможностью отмены
- **Панель настроек** (правый клик по значку трея → Опции → Настройки):
  внешний вид (цвет/шрифты), поведение (видимость панели Markdown по
  умолчанию, подтверждение удаления, действие по левому клику на
  значок трея), система (автозапуск, путь к данным с кнопкой
  «Открыть», экспорт/импорт резервной копии) и языки
- **Многоязычный интерфейс**: выбор языка в Настройках, причём название
  каждого языка написано на нём самом (например, «Español», а не
  «испанский») рядом с флагом. В комплекте — испанский, английский,
  французский и русский языки; каждый язык представляет собой отдельный
  JSON-файл в `src/i18n/`, автоматически обнаруживаемый как при сборке,
  так и во время выполнения
- **Подменю «Опции»** в меню трея: Справка (документация на GitHub),
  Поддержать автора, Просмотреть лицензию, Настройки и О программе
- Единственный экземпляр: если приложение уже запущено, повторный
  запуск не открывает вторую копию
- Автоматическое восстановление при перезапуске KWin в середине сеанса
  (сбой или `kwin_wayland --replace`): сохранение положения
  переподключается само, без необходимости перезапускать приложение
- Установщик удаляет осиротевшие правила KWin, оставшиеся от стикеров,
  удалённых в предыдущих сеансах
- Автозапуск через стандартную запись `.desktop` freedesktop (а не
  через «Фоновые службы» Plasma), включаемый и отключаемый в Настройках

## Хранение данных

Desktop Stickers следует стандарту **XDG Base Directory** — ничего не
хранится в отдельной произвольной папке в домашнем каталоге.

Стикеры хранятся в `$XDG_DATA_HOME/desktop-stickers/stickers.json`
(обычно `~/.local/share/desktop-stickers/stickers.json`):

```json
{
  "stickers": [
    {
      "id": "001",
      "name": "",
      "text": "Содержимое в Markdown",
      "color": "#FFD700",
      "x": 100,
      "y": 200,
      "width": 300,
      "height": 250,
      "pinned": false,
      "fontFamily": "Liberation Serif",
      "fontSize": 10,
      "created": "2026-08-17T10:30:00Z",
      "modified": "2026-08-17T15:45:00Z"
    }
  ]
}
```

Настройки приложения хранятся отдельно, в
`$XDG_CONFIG_HOME/desktop-stickers/settings.json` (обычно
`~/.config/desktop-stickers/settings.json`) — внешний вид, поведение,
автозапуск и язык.

> Обновляетесь с версии до v1.1.0? При первом запуске нового
> исполняемого файла ваши данные автоматически и незаметно переносятся
> со старого пути `~/.stickers/` в два указанных выше пути XDG. Никаких
> дополнительных действий не требуется.
