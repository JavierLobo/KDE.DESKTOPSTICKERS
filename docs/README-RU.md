Плавающие стикеры для рабочего стола KDE Plasma. Автономное
Qt6/QML-приложение (не плазмоид), устанавливаемое как обычная программа
с автозапуском — каждый стикер представляет собой отдельное окно без
декораций, с сохраняемыми положением и размером, а также возможностью
отображения на всех виртуальных рабочих столах для каждого стикера
отдельно (закрепление).

## Требования

- Plasma 6.x (проверено на версии 6.7.4) и KWin, сеанс Wayland
- Qt 6.5+ (`Core`, `Gui`, `Qml`, `Quick`, `Widgets`, `DBus`)
- CMake, Bash

## Установка

```bash
chmod +x scripts/install.sh
./scripts/install.sh
```

Собирает исполняемый файл, устанавливает его в
`~/.local/bin/kde-stickers` и регистрирует автозапуск. См.
[QUICKSTART-RU.md](QUICKSTART-RU.md) — полное руководство (первый
запуск, тестовые данные, устранение неполадок) и `QA_CHECKLIST.md` —
чек-лист ручной проверки.

## Возможности

- Создание стикеров из значка в системном трее или кнопки "+" на
  существующем стикере (появляется каскадом, со смещением от
  исходного), с последовательным id
- Перетаскивание по рабочему столу (реальное перемещение через
  `Window.startSystemMove()`), при этом реальное положение (сообщаемое
  KWin, а не Qt) сохраняется после каждого перетаскивания и
  восстанавливается при перезапуске благодаря правилу окна KWin для
  каждого стикера (`kdestickers-sticker-<id>`)
- Изменение размера за нижний правый угол — размер сохраняется и
  восстанавливается так же, как и положение
- Закрепление для каждого стикера (кнопка 📍/📌): включается
  индивидуально, чтобы стикер был виден одновременно на всех
  виртуальных рабочих столах, через то же правило окна KWin; без
  закрепления стикер существует только на том рабочем столе, где он был
  создан или перемещён. По умолчанию новый стикер создаётся без
  закрепления
- Редактирование текста в **полном Markdown** (заголовки, таблицы, код,
  цитаты, списки, жирный/курсив, ссылки, чекбоксы) с автоматическим
  переключением: клик — для редактирования, потеря фокуса — для
  возврата к отрисованному предпросмотру
- В предпросмотре ссылки кликабельны (открываются через системный
  обработчик URL), а блоки кода отображаются в рамке с выделенным фоном
- Прокручиваемое содержимое: длинная заметка никогда не выходит за
  пределы стикера, а область редактирования автоматически
  прокручивается, чтобы курсор оставался видимым при наборе текста
- Цвет фона: фиксированная палитра из 6 пастельных тонов (назначается
  случайно каждому новому стикеру) или свободный выбор цвета
- Имя для каждого стикера, редактируемое в Панели стикеров: если не
  задано, определяется автоматически по первой непустой строке текста
  (без ведущих символов заголовка `#`). Обрезается до 30 символов как в
  заголовке стикера (`#<id> | <имя или резервное значение>`), так и в
  меню трея / Панели
- Значок в системном трее показывает список из 10 последних изменённых
  заметок (без постраничной навигации) — каждая строка открывает
  заметку или переводит на неё фокус. "Панель стикеров" в том же меню
  открывает окно с полным, неограниченным списком: открытие,
  переименование и удаление (с подтверждением) каждой заметки
- Кнопка "✕" на стикере только закрывает его окно — заметка по-прежнему
  существует и может быть открыта снова из меню трея. Удаление заметки
  — отдельное действие, доступное только из Панели стикеров, и всегда
  запрашивает подтверждение; при удалении также удаляется её правило
  окна KWin
- Сохранение данных в `~/.stickers/stickers.json`
- Единственный экземпляр: если приложение уже запущено, повторный
  запуск не открывает вторую копию
- Автоматическое восстановление при перезапуске KWin в середине сеанса
  (сбой или `kwin_wayland --replace`): сохранение положения
  переподключается само, без перезапуска приложения
- Установщик удаляет осиротевшие правила KWin, оставшиеся от стикеров,
  удалённых в предыдущих сеансах
- Автозапуск через стандартную запись `.desktop` freedesktop (а не
  через "Фоновые службы" Plasma)

## Хранение данных

Стикеры сохраняются в `~/.stickers/stickers.json`:

```json
{
  "stickers": [
    {
      "id": "001",
      "name": "",
      "text": "Contenido en Markdown",
      "color": "#FFD700",
      "x": 100,
      "y": 200,
      "width": 300,
      "height": 250,
      "pinned": false,
      "created": "2026-08-17T10:30:00Z",
      "modified": "2026-08-17T15:45:00Z"
    }
  ]
}
```
